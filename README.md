# Mein Budget – Offline-Prototyp

## Starten
- ZIP entpacken.
- `index.html` öffnen. Für zuverlässige Offline-Installation als PWA die Dateien auf einen statischen HTTPS-Host legen (z. B. GitHub Pages) und die Seite einmal öffnen; danach kann sie zum Home-Bildschirm hinzugefügt werden.
- Alle Finanzdaten werden lokal im Browser (`localStorage`) gespeichert. Es gibt keine Anmeldung und keinen Server.

## Funktionen
- Dashboard mit verfügbarem Betrag, Monatsübersicht und letzten Buchungen
- Buchungen anlegen, bearbeiten und einzeln löschen
- Monatsnavigation
- Budgetkategorien und Monatslimits
- Sparziele mit Fortschritt und Einzahlungen
- Fixkosten mit monatlicher, vierteljährlicher, halbjährlicher, jährlicher oder einmaliger Frequenz
- Schuldenübersicht und Ratenverbuchung
- Kalenderansicht, Auswertung, JSON-Export/-Import
- Fünf Logo-Varianten

## Hinweis
Die Beispielwerte sind Demo-Daten. Dies ist eine eigenständige, lokal speichernde Web-App/PWA-Vorlage, keine native iOS-App und keine Finanzberatung. Auf iOS kann eine PWA offline laufen, wenn sie über HTTPS bereitgestellt und zuvor geladen wurde.
